# Portfolio: A Dechin Changappa
Open `index.html` in a browser. Edit everything in `js/content.js` (look for PLACEHOLDER). Replace images in `assets/` keeping the same filenames (profile.jpg, project-01.jpg, client-01.png, testimonial-01.jpg, gallery-01.jpg). Put your resume at `documents/Resume.pdf`.
**Contact form:** create a free form at formspree.io or web3forms.com and paste the URL into `formEndpoint`. Until then the form shows a "not connected" notice.
**Deploy:** push the folder to GitHub and enable Pages (Settings > Pages), or drag the folder onto netlify.com/drop.
